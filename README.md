# Raynato Lienardy — CV

Personal CV and portfolio website. Clean, responsive, single-page design optimized for recruiters and GitHub Pages.

## Features

- Responsive design (desktop, tablet, mobile)
- English / Indonesian language switcher
- Client-side PDF download with automatic language-aware filename
- SEO and Open Graph metadata
- Favicon support
- GitHub Pages compatible
- No backend or external dependencies

## Tech Stack

- HTML5 (semantic markup)
- CSS3 (modern layout, responsive design, print optimization)
- JavaScript (minimal, vanilla)
- html2pdf.js (client-side PDF generation)

## Live CV

https://raylienardy.github.io/cv/

## How to Use

1. Open `index.html` in a browser
2. Use the EN/ID switcher in the bottom-right corner to change language
3. Click the PDF button to download CV with automatic filename

## Edit Content

All CV content is in `index.html`. Edit directly—no build step required. Sections are clearly marked with HTML comments.

## Deployment

1. Push to GitHub repository
2. Enable GitHub Pages: Settings → Pages → Source: Deploy from branch `main` / root
3. Site will be live at `https://raylienardy.github.io/cv/`
